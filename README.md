# 🪞 Mr. Inside

> **내 감정과 행동의 이유를 함께 들여다보는 생성형 AI 자기이해 서비스**

**Look inside. Understand yourself.**

---

## 📌 프로젝트 소개

**Mr. Inside**는 사용자가 자신의 감정, 고민, 행동을 자연스럽게 이야기하면 생성형 AI가 대화 내용을 분석하여 반복되는 **상황·생각·감정·행동 패턴**을 발견하도록 돕는 자기이해 서비스입니다.

단순히 사용자의 말을 듣고 답변하는 챗봇이 아니라, 과거의 대화 기록을 기반으로 비슷한 경험을 연결하고 사용자가 스스로 인식하지 못했던 반복적인 패턴을 발견하도록 돕는 것을 목표로 합니다.

---

## 🎯 프로젝트 목적

사람은 일상에서 비슷한 감정과 행동을 반복하지만,

- 왜 이런 감정을 느끼는지
- 왜 특정 상황에서 같은 행동을 반복하는지
- 어떤 상황에서 불안하거나 부담을 느끼는지

스스로 객관적으로 파악하기 어려운 경우가 많습니다.

Mr. Inside는 사용자의 자연어 대화를 장기간 분석하여

**상황 → 생각 → 감정 → 행동 → 결과**

의 흐름을 구조화하고, 반복적으로 나타나는 특징을 사용자에게 알려줍니다.

이를 통해 사용자가 자신의 행동과 감정을 더 깊게 이해하고 자기성찰을 할 수 있도록 지원합니다.

---

## 👤 예상 사용자

- 자신의 감정이나 행동의 이유가 궁금한 사람
- 비슷한 고민이나 행동을 반복한다고 느끼는 사람
- 자기이해와 자기성찰에 관심 있는 대학생 및 성인
- 자신의 감정을 말로 정리하기 어려운 사람
- 미루기, 회피, 과도한 걱정 등 반복되는 행동을 이해하고 싶은 사람

---

## 💡 주요 기능

### 1. AI 심층 대화

사용자가 자신의 고민이나 경험을 자유롭게 입력하면 AI가 현재 대화에 필요한 추가 질문을 생성합니다.

예시

사용자:

> 요즘 해야 할 일이 있는데 계속 미루게 돼.

AI:

> 그 일을 시작하려고 할 때 가장 먼저 드는 감정은 부담감, 귀찮음, 불안 중 어디에 가까워?

---

### 2. 대화 내용 구조화

사용자의 자연어 대화를 다음과 같은 형태로 구조화합니다.

```json
{
  "situation": "과제가 많이 쌓여 있음",
  "thought": "제대로 해야 한다",
  "emotion": ["부담감", "불안"],
  "behavior": "과제 시작을 미룸",
  "result": "유튜브를 본 뒤 죄책감을 느낌"
}

구조화된 정보는 이후 패턴 분석에 사용됩니다.
3. Pattern Finder
여러 대화가 축적되면 반복적으로 나타나는 행동과 감정의 흐름을 분석합니다.
예시
해야 할 일이 많아짐
        ↓
완벽하게 해야 한다는 생각
        ↓
부담감 증가
        ↓
시작을 미룸
        ↓
다른 행동으로 회피
        ↓
마감 직전 몰입

AI는 이러한 내용을 심리 진단으로 단정하지 않고 사용자의 기록에서 관찰된 반복적인 경향으로 제시합니다.
4. 과거 대화 연결
현재 경험과 과거의 비슷한 경험을 연결합니다.
예시
이 상황은 이전에 이야기했던
‘갈등이 예상되면 자신의 의견을 뒤로 미루는 패턴’과
비슷하게 나타나고 있어요.

5. Inside Report
일정 기간 동안 축적된 대화를 분석하여 사용자의 자기이해 리포트를 제공합니다.
예시
최근 자주 나타난 감정
- 부담감
- 불안
- 답답함

반복적으로 나타난 상황
- 해야 할 일이 많을 때
- 다른 사람의 평가가 예상될 때
- 갈등이 발생할 가능성이 있을 때

현재 탐색 중인 패턴
높은 기준 → 부담감 → 시작 지연

6. Deep Dive
사용자가 특정 행동이나 감정을 선택해 AI와 더욱 깊게 대화할 수 있는 기능입니다.
예시
나는 왜 다른 사람이 불편해지는 걸 그렇게 신경 쓰는 걸까?

AI는 관련된 과거 대화와 현재 답변을 연결해 추가 질문을 생성합니다.
🤖 생성형 AI 활용 방식

⚠️ 서비스 한계 및 주의사항
Mr. Inside는 전문 심리상담사나 의료진을 대체하는 서비스가 아닙니다.
AI가 제공하는 분석은 사용자의 대화에서 관찰된 패턴을 기반으로 한 자기성찰을 위한 참고 정보입니다.
정신건강 질환을 진단하거나 치료하는 것을 목적으로 하지 않습니다.
```
